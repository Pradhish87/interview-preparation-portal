# Interview Preparation Portal

A cloud-based web application designed to help students prepare for technical and placement interviews through aptitude practice, mock tests, and performance tracking.

## 🚀 Features

- User Registration and Login
- Firebase Authentication
- Secure User Dashboard
- Aptitude Practice
  - Quantitative Aptitude
  - Logical Reasoning
  - Verbal Ability
- Mock Interview Test
- 10-minute Mock Test Timer
- Automatic Score Calculation
- Test Result Storage using Firebase Firestore
- Dashboard Performance Statistics
- Responsive Design for Desktop and Mobile

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Firebase Authentication
- Firebase Firestore
- Firebase Hosting
